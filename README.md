# design-taste

A UI design skill distilled from two pieces of work: **Gluten** and **Assembled**.

It is not a component library, a theme, or a moodboard. It is a set of decisions about what to keep, what to remove, and how one state becomes another.

The short version: the work is the interface. Choose one physical idea. Build the hand-off before the polish. Say it once. Sweat the last 5%.

## What is in here

| File | Job |
| --- | --- |
| `SKILL.md` | The skill itself: laws, build order, composition, type, colour, copy, motion, interaction, performance, accessibility, red flags, the final test. |
| `references/case-studies.md` | Gluten and Assembled, decision by decision, with the numbers and the reasons. |
| `references/small-things.md` | The small moves — the ones that are easy to skip and make the difference. |

## How to use it

This follows the `SKILL.md` convention used by agent skills.

- Drop the `design-taste/` folder into your agent's skills directory, or
- point the agent at `SKILL.md` and keep the `references/` folder beside it.

The main file is written to be read in full before starting. The references are there when you need the reasoning or the punch list.

Use it when:

- a portfolio, photography site or image-led page should feel like an experience rather than a template;
- an interface needs a transition that does not look like a cut;
- a page has too much text, too many labels, or too much chrome around the work;
- you are reviewing a UI for the last 5% — seams, edges, the frame where something disappears.

## Provenance

Built from the actual code and decisions of two projects:

- **Gluten** — a scroll-driven portfolio for 3D work. See it at [gluten.cloudflare-d2b.workers.dev](https://gluten.cloudflare-d2b.workers.dev).
- **Assembled** — a photograph portfolio operated by click. A local experiment: thirty thousand particles become a print, hold, and break from the rim inward.

The case studies describe what those pieces do and why. They are examples, not templates. Do not copy the surface; copy the decision.

## What it is not

- Not a brand guideline.
- Not a list of effects to bolt on.
- Not permission to add motion. Most of it is permission to remove things.
